Panduan Operasional & Alur Sistem Lembur (SILEKA)

Dokumentasi terpadu standar operasional Surat Perintah Lembur (SPL) digital di Pabrik Kelapa Sawit PT. Letawa. Pada format dokumen konvensional sebelumnya, nama dan nomor employee karyawan memang sudah tercetak di blangko, namun Mandor tetap harus menulis tangan jam dan jenis pekerjaan satu per satu setiap hari, lalu Admin mengetik ulang ke Excel. SILEKA mentransformasi alur ini menjadi sistem digital otomatis yang efisien, hemat biaya kertas, dan bebas salah hitung.

✕ Pencatatan Berbasis Kertas
Data lembur (SPL) masih ditulis manual di kertas, sehingga rawan rusak, basah/terkena minyak pabrik, hilang, atau memiliki tulisan tangan yang sulit dibaca saat hendak direkap.
✕ Beban Rekapitulasi Harian
Setiap pagi, kertas laporan disetorkan oleh Mandor dan Admin harus mengetik ulang seluruh data fisik tersebut ke file Excel secara manual satu per satu.
✕ Pemborosan Biaya & Ruang Arsip
Pencetakan blangko SPL setiap hari memakan banyak biaya kertas & tinta, menghasilkan penumpukan limbah dokumen, serta menghabiskan ruang lemari arsip.
✕ Pencarian Arsip Data Sulit
Jika terjadi komplain atau selisih perhitungan gaji, Admin kesulitan melacak riwayat lembur karyawan karena harus membongkar tumpukan berkas arsip kertas fisik.

Perbandingan Sistem Konvensional vs SILEKA

Perubahan mendasar operasional pencatatan lembur di pabrik
Aspek Pengelolaan Sistem Konvensional (Kertas Fisik) Sistem Digital (SILEKA)
Pengisian Jam & Tugas
✕ Tulis Manual Tiap Baris
Walaupun nama dan ID sudah tercetak di blangko, Mandor tetap harus menulis tangan jam mulai, jam selesai, dan jenis tugas pada 20–35 baris karyawan setiap hari.
✓ Preset Jam Cepat 1 Klik
Mandor cukup menggunakan bar Preset Jam untuk mengisi jam mulai dan selesai serentak ke seluruh regu dalam 1 detik, lalu menyesuaikan jenis tugas dan jam yang berbeda.
Rekapitulasi Harian Admin
✕ Mengetik Ulang ke Excel
Setiap pagi lembaran kertas disetor ke kantor; Admin harus meluangkan waktu mengetik ulang seluruh data fisik tersebut ke file Excel satu per satu.
✓ Otomatis Tersimpan di Sistem
Begitu Mandor klik 'Simpan', seluruh data otomatis terekam rapi di sistem. Admin tidak perlu lagi mengetik ulang ke Excel setiap pagi.
Biaya Kertas & Ruang Arsip
✕ Boros Kertas & Limbah Menumpuk
Pencetakan blangko kertas setiap hari menghabiskan biaya operasional dan lembaran fisik menumpuk di lemari arsip berdebu.
✓ 100% Paperless di Database
Semua data tersimpan aman di database cloud.
Penelusuran Komplain & Riwayat
✕ Bongkar Tumpukan Arsip Kertas
Jika ada komplain selisih perhitungan lembur, Admin harus membongkar tumpukan map kertas berbulan-bulan ke belakang.
✓ Pencarian Instan Hitungan Detik
Admin dan karyawan dapat langsung memfilter tanggal dan riwayat lembur secara real-time di aplikasi tanpa repot mencari dokumen fisik.

Alur Kerja Operasional Harian (Workflow)

Proses dari pembuatan instruksi hingga rekapitulasi penggajian
Tahap 1 — Input SPL Harian Pelaksana: Mandor Lapangan

Pengisian Jam Lembur Kolektif Berbasis Shift

Mandor login ke sistem SILEKA, membuka menu Buat SPL, dan memilih tanggal operasional. Sistem langsung memuat seluruh anggota regu shift mandor tersebut secara otomatis . Mandor menggunakan fitur Preset Bar untuk mengisi jam mulai & selesai secara serentak ke seluruh regu dalam 1 klik, lalu mengisi rincian tugas. Bagi karyawan yang tidak lembur (izin/cuti/sakit/HK), toggle diubah ke 'Tidak Lembur' dan keterangannya diisi pada Jenis Pekerjaan. Klik 'Simpan Semua Data Lembur'.

✓ Pilih tanggal operasional lembur
✓ Anggota regu shift otomatis muncul di tabel
✓ Preset Jam massal mengisi serentak 1 klik
✓ Keterangan alasan bagi yang Tidak Lembur
✓ Simpan data langsung terekam ke cloud
Tahap 2 — Validasi Mandiri di HP Pelaksana: Karyawan Pelaksana

Pemeriksaan & Persetujuan Digital (ACC) oleh Karyawan

Setelah selesai jam kerja, karyawan membuka aplikasi SILEKA dari browser smartphone masing-masing. Di dashboard pribadi, karyawan melihat data rencana lembur yang telah dibuatkan mandor untuk dirinya (jam mulai, jam selesai, jenis tugas). Jika data sudah sesuai dengan fakta kerja di lapangan, karyawan menekan tombol ACC (status berubah menjadi Disetujui). Jika terdapat perbedaan jam, karyawan menekan tombol Tolak disertai alasan agar diperbaiki oleh Mandor.

✓ Akses mandiri dari HP masing-masing
✓ Periksa jam mulai s/d selesai dan tugas
✓ Klik 'ACC' untuk persetujuan digital sah
✓ Klik 'Tolak' jika terdapat selisih jam kerja
Tahap 3 — Rekapitulasi Otomatis Pelaksana: Admin Personalia

Pemantauan & Rekapitulasi Data Tanpa Ketik Ulang Excel

Setiap pagi Admin tidak perlu lagi menerima kertas dari mandor dan mengetik ulang seluruh data ke Excel. Admin cukup membuka dashboard SILEKA; seluruh rekaman data lembur dari seluruh shift sudah tersaji lengkap, transparan, dan terakumulasi secara otomatis. Jika terjadi komplain selisih jam dari karyawan, Admin dapat mencari riwayat tanggal lampau dalam hitungan detik. Laporan siap diekspor untuk dasar perhitungan penggajian lembur bulanan.

✓ Bebas tugas mengetik ulang ke Excel setiap pagi
✓ Perhitungan durasi otomatis (termasuk lintas malam)
✓ Pencarian riwayat komplain instan via filter tanggal
✓ Ekspor rekapitulasi data lembur untuk payroll
Opsi Cadangan — Cetak Fisik PROS-HCM-02 Pelaksana: Mandor / Admin (Bila Diperlukan)

Pencetakan Kertas Fisik untuk Tanda Tangan Basah

Sistem SILEKA didesain 100% paperless dengan persetujuan digital di aplikasi. Namun Admin juga dapat menggunakan fitur Cetak SPL. Sistem akan menghasilkan formulir standar resmi PROS-HCM-02 pas 1 lembar kertas A4 portrait yang bersih dari elemen navigasi web, siap dicetak untuk ditandatangani basah secara fisik di kantor.

✓ Format resmi PROS-HCM-02 pas 1 halaman A4 Portrait
✓ Kolom lengkap: No, ID Employee, Nama, Stasiun, Jam & Paraf
